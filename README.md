# Banking App Project

Simple banking application built with a Python FastAPI backend and a frontend to be added.

## Project Structure

```text
backend/
  app/
    main.py
    controllers/
    services/
    repositories/
    models/
    schemas/
    data/
    temp/
  tests/
frontend/
docs/
```

`backend/app/temp/` is for code we want to keep but have not connected to the final architecture yet.
